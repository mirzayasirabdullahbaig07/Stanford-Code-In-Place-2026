## 📚 About the Program

[Code in Place](https://codeinplace.stanford.edu/) is a free introductory programming course from Stanford University. It covers the fundamentals of Python programming through a structured, hands-on curriculum with real Stanford instructors and section leaders. The 2026 edition spans 7 weeks, progressing from Karel the Robot basics all the way to a self-designed final project.

## 📅 Weekly Breakdown

### 🤖 Week 1 — Karel the Robot: Basics
Introduction to programming through Karel, a simple robot that moves in a grid world. Covers commands, loops, and following step-by-step instructions.

| File | Description |
|------|-------------|
| `2026 Karel.py` | Introductory Karel exercises for 2026 |
| `Beeper Path.py` | Navigate Karel along a path of beepers |
| `Jigsaw Karel.py` | Solve a jigsaw-style grid puzzle |
| `Karel's Home.py` | Guide Karel back to its starting position |
| `Piles.py` | Build and manage piles of beepers |
| `Warmup.py` | Basic warmup exercises with Karel |

---

### 🔁 Week 2 — Karel the Robot: Control Flow
Builds on Karel with conditionals, while loops, and creative problem-solving.

| File | Description |
|------|-------------|
| `Create Your Own Karel.py` | Custom Karel world designed from scratch |
| `Fill Karel.py` | Fill an entire row or world with beepers |
| `Optional CheckerBoard.py` | Draw a checkerboard pattern with Karel |
| `Optional Midpoint Karel.py` | Find and mark the midpoint of a row |
| `Stone Mason Karel.py` | Repair columns of missing beepers |

---

### 🐍 Week 3 — Python Basics: Variables & Expressions
Transition to real Python. Covers variables, data types, user input, and expressions.

| File | Description |
|------|-------------|
| `Dog years.py` | Convert human age to dog years |
| `Hello Name.py` | Personalized greeting program |
| `Multiply Two Numbers.py` | Basic arithmetic with user input |
| `Optional Haiku Generator.py` | Generate a random haiku |
| `Sunrise Fill In The Blanks.py` | Complete a sunrise-themed program |
| `n-sided dice.py` | Simulate rolling an n-sided dice |

---

### 🔄 Week 4 — Control Flow: Loops & Conditionals
Deep dive into for loops, while loops, if/else, and building interactive console programs.

| File | Description |
|------|-------------|
| `10 Random.py` | Generate and display 10 random numbers |
| `Create Your Own Console.py` | Custom interactive console program |
| `Double It.py` | Double a number until a threshold is hit |
| `Joke Bot.py` | Interactive joke-telling chatbot |
| `Khansole Academy.py` | Math quiz game inspired by Khan Academy |
| `Liftoff.py` | Countdown and liftoff simulation |
| `Optional Game of Nimm.py` | Two-player strategy game |

---

### 🎨 Week 5 — Graphics: Drawing with Code
Using Python's graphics library to draw shapes, scenes, and patterns on a canvas.

| File | Description |

| `Draw Flag.py` | Draw a country flag using shapes |

### 📋 Week 6 — Lists & Data
Working with Python lists, loops over collections, and building data-driven programs.

| File | Description |

## ⚙️ Getting Started

### Prerequisites
- Python 3.x
- Streamlit (for the final project)

### Installation

```bash
# Clone the repository
git clone https://github.com/mirzayasirabdullahbaig07/Stanford-Code-In-Place-2026.git
cd Stanford-Code-In-Place-2026
```

### Running the Final Project

```bash
pip install streamlit
cd "Week 7 Final Project"
streamlit run app.py
```

### Running Other Assignments

Most assignments can be run directly:

```bash
python "Week 3/Dog years.py"
```

> **Note:** Karel and graphics assignments require the Stanford Code in Place environment or the `cs106ap` library.
